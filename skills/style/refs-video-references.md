## Install

```bash
# Claude Code
claude mcp add --transport http refs https://refs.video/mcp

# claude-ai
Customize → Connectors → Add custom connector → https://refs.video/mcp

# Codex
codex mcp add refs --url https://refs.video/mcp

# mcp
https://refs.video/mcp
```
