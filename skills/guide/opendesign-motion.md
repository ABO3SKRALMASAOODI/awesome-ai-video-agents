# OpenDesign Motion by OpenDesign

Open-source motion design workspace: any agent, any model writes HyperFrames motion graphics and exports MP4.

- **Type:** Guides · Animation
- **Status:** live
- **Publisher:** OpenDesign (nexu-io)
- **License:** Apache-2.0
- **Source:** <https://github.com/nexu-io/open-design>
- **Works in:** Claude Code, Codex, Cursor, OpenClaw, mcp
- **Tags:** `motion-graphics` `hyperframes` `open-source` `desktop` `any-model` `mcp` `launch` `app`
- **Full card, kept current:** <https://varg.ai/how-to/skills/opendesign-motion.md>
